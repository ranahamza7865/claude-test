# Feline — The Art of Cats

## Project Overview
An immersive, award-winning 3D website dedicated to the beauty and elegance of cats. Built with React, Three.js, and modern web technologies.

## Technology Stack
- React.js with Vite
- Three.js + React Three Fiber
- @react-three/fiber and @react-three/drei
- GSAP for animations and scroll effects
- Framer Motion for UI animations
- Tailwind CSS with custom design system

## Available Scripts
- `npm run dev` — starts development server at http://localhost:5173
- `npm run build` — builds for production
- `npm run preview` — previews production build
- `npm run lint` — runs Oxlint

## Design System
- **Colors**: Cream (#faf9f6), Ivory (#fff8e6), Charcoal (#1a1a1a), Gold (#ffe6cc)
- **Fonts**: Serif (Georgia, Cambria) + Sans-serif (Inter, system-ui)
- **Responsive**: Mobile-first, prefers-reduced-motion support

## Sections
1. Hero — Cinematic 3D with realistic Persian cat
2. Cat Collection — 6 breed cards with interactions
3. Scroll Experience — GSAP ScrollTrigger animations
4. Interactive Cat — Mouse tracking, blinking, tail
5. Gallery — Premium photography layout
6. Final — "THE WORLD IS MORE BEAUTIFUL WITH CATS."
