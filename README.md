# Feline — The Art of Cats

An immersive, award-winning 3D website dedicated to the beauty and elegance of cats.

## Project Overview

**Feline** is a visually stunning, ultra-realistic 3D website experience that celebrates the artistry of cats. Built with modern web technologies, it delivers an Apple-level interactive experience that stands apart from typical pet shop websites.

## Technology Stack

- **React.js** — for the user interface
- **Three.js** — for 3D graphics
- **React Three Fiber** — Three.js React integration
- **@react-three/drei** — Three.js helpers and utilities
- **GSAP** — advanced animations and scroll-triggered effects
- **Framer Motion** — UI animations
- **Tailwind CSS** — styling
- **Lucide React** — icons

## Website Sections

### 1. Hero Section
- Full-screen immersive 3D environment
- Realistic fluffy white Persian cat as the main character
- Cinematic lighting with soft golden sunlight, volumetric fog, and realistic shadows
- Floating particle system
- Large elegant typography: "BEAUTY HAS A SOUL."
- Subtitle: "Discover the extraordinary world of feline elegance."
- Magnetic animated Explore button
- Cat subtly moves head and eyes based on mouse position

### 2. Cat Collection Section
- Showcases 6 beautiful cat breeds:
  - Persian Cat
  - Maine Coon
  - Bengal Cat
  - Ragdoll Cat
  - British Shorthair
  - Siamese Cat
- Each with large realistic visuals, breed name, and short description
- Interactive hover animations
- Smooth transitions when selecting breeds

### 3. Cinematic Scroll Experience
- GSAP ScrollTrigger-powered scroll animations
- Camera travels through 3D environment
- Parallax backgrounds
- Typography and visual element animations
- Smooth section-to-section transitions

### 4. Interactive Cat Experience
- Mouse influences cat head direction
- Click triggers cute reaction
- Blinking and tail movement animations
- Interactive floating elements
- Experience feels alive and responsive

### 5. Premium Gallery Section
- Editorial layout with different image sizes
- Elegant typography
- Smooth hover effects
- Click-to-zoom functionality

### 6. Final Section
- Beautiful cat in cinematic environment
- Main heading: "THE WORLD IS MORE BEAUTIFUL WITH CATS."
- Animated button: "EXPLORE THE COLLECTION"
